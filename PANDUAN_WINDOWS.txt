PANDUAN WINDOWS 10/11 — SIMK ITP B REVISI 0.2.9

PERSIAPAN
- Node.js minimal 22.12. Laptop pengguna sebelumnya memiliki Node.js 26.13.1 dan npm 11.20.0, yang memenuhi syarat.
- Koneksi internet aktif dibutuhkan pada instalasi pertama untuk mengambil paket dan membuat package-lock.json asli.
- Tidak perlu mengubah PowerShell Execution Policy. Peluncur menggunakan npm.cmd.

CARA MENJALANKAN
1. Unduh SIMK_ITP_B_FINAL_0_2_9.zip.
2. Klik kanan ZIP > Extract All / Ekstrak Semua.
3. Buka folder SIMK_ITP_B_FINAL_0_2_9.
4. Klik dua kali MULAI_SIMK.bat.
5. Biarkan jendela terminal terbuka. Proses pertama dapat lebih lama karena npm mengunduh dependency.
6. Peluncur membuat package-lock.json asli dengan npm, memvalidasinya, memverifikasi cache, lalu memasang dependency menggunakan npm ci --include=dev --ignore-scripts.
7. Peluncur menjalankan npm rebuild esbuild@0.28.2 secara khusus; skrip paket lain tetap ditahan.
8. Peluncur memverifikasi TypeScript dan Vite, menjalankan 48 tes otomatis, TypeScript typecheck, dan Vite build. Jika salah satu tahap utama gagal, website tidak dijalankan.
9. Jika lulus, browser membuka http://127.0.0.1:5173. Biarkan jendela terminal terbuka selama website digunakan.
10. Untuk menghentikan server, klik jendela terminal lalu tekan Ctrl+C.

TENTANG package-lock.json
- File ini sengaja tidak direkayasa atau dibuat parsial. Lockfile yang benar harus berisi seluruh versi dependency transitif yang diselesaikan registry npm.
- Pada pemakaian pertama, MULAI_SIMK.bat membuat package-lock.json lengkap secara otomatis. Setelah muncul, file tersebut disimpan di folder SIMK dan harus ikut ketika folder proyek disalin atau diunggah.
- Jika internet/registry tidak dapat diakses, tahap pembuatan lockfile berhenti dengan pesan yang jelas. Tidak ada lockfile palsu yang digunakan.

JIKA GAGAL
- Jangan menjalankan npm audit fix --force.
- Jangan menghapus package-lock.json atau node_modules sebagai tebakan.
- Jangan ubah PowerShell Execution Policy.
- Ambil screenshot seluruh jendela terminal, termasuk perintah dan pesan error.

BATAS PENGGUNAAN
- Paket ini adalah prototipe lokal. Login lokal dan localStorage bukan autentikasi produksi atau database terpusat.
- Folder Supabase memuat fondasi migration, RLS dan Edge Functions, tetapi belum diterapkan/dibuktikan di project staging dan belum semua halaman React tersambung ke sana.
- Pusat AI lokal adalah demo berbasis aturan, bukan layanan AI live.
- Jangan masukkan roster/NIM/presensi asli atau deploy publik sebelum integrasi Auth, Database, RLS, Storage, Edge Functions, AI provider dan pengujian multiakun/browser selesai.
